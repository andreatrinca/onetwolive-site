What’s new in OneTwoLive.

New features, improvements and the public version history of OneTwoLive for Windows.

Latest release

OneTwoLive 1.1.0

September 12, 2026Current

A substantial playback and control update focused on more precise live performance workflows and faster stage operation.

  • Delay, Trim, Fade and Tail controls for more precise track playback and endings.
  • Fade Stop to stop a track smoothly instead of cutting it immediately.
  • Configurable keyboard and pedalboard shortcuts for Play/Pause, Stop, Fade Stop, Previous Track and Next Track.
  • Refreshed player and toolbar icons for a clearer and more consistent interface.
  • General usability and stability improvements.

Previous versions

Previous standalone build

Maintenance release distributed through the standalone installer. A separate detailed public changelog was not published for this build.

OneTwoLive 1.0.2

First Microsoft Store release

The first OneTwoLive version published on Microsoft Store. The release included the core stage-ready feature set:

  • Setlist playback and large stage-friendly player controls.
  • Speed, pitch and gain adjustment tools.
  • Track normalization and flexible audio loading.
  • Live Display, pre-show checks and setlist file relocation support.
