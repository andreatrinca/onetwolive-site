Release notes

What’s new in OneTwoLive.

New features, improvements and the public version history of OneTwoLive for Windows.

Latest release

OneTwoLive 1.1.1

September 18, 2026Current

Maintenance release focused on interface readability and control accessibility on Full HD displays using Windows display scaling.

  • Fixed a layout issue that could hide important playback and audio controls at higher Windows scaling settings.
  • The main player area is now vertically scrollable when the available vertical space is limited.
  • Levels, Spectrum and EQ remain accessible whenever they are enabled.
  • Live Mode now returns the player view to the top so the current track title and main playback controls are immediately visible.

Release history

Previous versions

OneTwoLive 1.1.0

September 12, 2026

Playback and control update focused on more precise live performance workflows and faster stage operation.

  • New Delay, Trim, Fade and Tail controls.
  • New Fade Stop command.
  • Configurable keyboard and pedalboard shortcuts.
  • Refreshed player and toolbar icons.
  • General usability and stability improvements.

OneTwoLive 1.0.3

Previous standalone build

Maintenance release distributed through the standalone installer. A separate detailed public changelog was not published for this build.

OneTwoLive 1.0.2

First Microsoft Store release

The first OneTwoLive version published on Microsoft Store. The release included the core stage-ready feature set:

  • Setlist playback and large stage-friendly player controls.
  • Speed, pitch and gain adjustment tools.
  • Track normalization and flexible audio loading.
  • Live Display, pre-show checks and setlist file relocation support.
